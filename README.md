## 🚀 Publication sur GitHub Pages (hébergement gratuit)

### Étape 1 — Activer GitHub Pages

1. Allez sur votre dépôt GitHub : `https://github.com/abdoul21091999/abdoul21091999`
2. Cliquez sur **Settings** (⚙️)
3. Dans le menu gauche, cliquez sur **Pages**
4. Sous **Branch**, sélectionnez la branche `claude/darou-karim-portfolio-dex0hp` (ou `main` après fusion)
5. Choisissez le dossier **`/ (root)`**
6. Cliquez **Save**

### Étape 2 — Créer une Pull Request (pour fusionner dans main)

1. Allez sur l'onglet **Pull Requests** du dépôt
2. Créez une PR de `claude/darou-karim-portfolio-dex0hp` → `main`
3. Fusionnez la PR
4. Retournez dans **Settings > Pages** et sélectionnez la branche `main`

### Étape 3 — Accéder au site

Votre site sera disponible à :
```
https://abdoul21091999.github.io/abdoul21091999/
```

> ⏱ La publication prend 1 à 5 minutes après activation.

## 🌐 Référencement Google (SEO)

Pour que votre site apparaisse sur Google :

### 1. Soumettre sur Google Search Console

1. Allez sur [search.google.com/search-console](https://search.google.com/search-console)
2. Connectez-vous avec votre compte Google
3. Cliquez **Ajouter une propriété**
4. Entrez votre URL : `https://abdoul21091999.github.io/abdoul21091999/`
5. Vérifiez la propriété (méthode HTML tag recommandée)
6. Allez dans **Sitemaps** → entrez `sitemap.xml` → **Soumettre**

### 2. Soumettre sur Bing (optionnel)

1. Allez sur [bing.com/webmasters](https://www.bing.com/webmasters)
2. Importez depuis Google Search Console ou ajoutez manuellement

### 3. Délai d'indexation

Google indexe généralement les nouveaux sites en **1 à 4 semaines**.
