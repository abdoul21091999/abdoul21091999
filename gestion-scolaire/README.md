# نظام إدارة رسوم المدرسة

برنامج ويب كامل لإدارة **رسوم التسجيل** و**الرسوم الشهرية** للطلاب، يعمل بالكامل من المتصفح. يمكن استخدامه محليًا بدون خادم (البيانات في `localStorage`)، أو ربطه اختياريًا بمزامنة مشتركة فورية بين عدة أجهزة (Firebase).

## المزايا

- **بوابة اختيار القسم**: عند فتح التطبيق (بعد إعداد المزامنة إن وُجدت) تظهر شاشة اختيار بين قسمين مستقلين: **المعهد الإسلامي** و**مدرسة تحفيظ القرآن**. اختيارك يُحفظ تلقائيًا على هذا الجهاز، وتظهر القائمة الجانبية بعده وبها فقط عناصر القسم المختار (مع بقاء الإعدادات والنسخ الاحتياطي مشتركين بين القسمين). يمكن التبديل بين القسمين في أي وقت بزر "🔄" أسفل القائمة الجانبية.
- **لوحة تحكم**: إحصاءات فورية (عدد الطلاب، المحصّل هذا الشهر، المتبقي من رسوم التسجيل والرسوم الشهرية، آخر الدفعات).
- **إدارة الطلاب**: تسجيل/تعديل/حذف الطلاب، تحديد القسم الدراسي، رسوم تسجيل ورسم شهري خاص لكل طالب عند الحاجة، بحث وتصفية حسب القسم وحالة السداد.
- **الإخوة وفاتورة عائلية موحّدة**: من صفحة تفاصيل الطالب يمكن إضافة ابن آخر لنفس ولي الأمر بضغطة واحدة (تُعبَّأ بياناته تلقائيًا)، وإصدار **فاتورة عائلية واحدة** تجمع مستحقات كل الأبناء (رسوم تسجيل + رسوم الشهر) في فاتورة واحدة قابلة للطباعة بدل إرسال فاتورة منفصلة لكل ابن — يتم التجميع تلقائيًا حسب رقم هاتف ولي الأمر.
- **الأقسام الدراسية**: إنشاء أقسام مع رسم شهري افتراضي لكل قسم.
- **تسجيل الدفعات**: ثلاثة أنواع — **رسوم تسجيل + الشهر الأول معًا** (الخيار الافتراضي، لأن ولي الأمر غالبًا يدفعهما دفعة واحدة عند التسجيل)، أو رسوم تسجيل فقط، أو رسوم شهرية تغطي شهرًا واحدًا أو عدة أشهر متتالية دفعة واحدة (شهر، 3 أشهر، 6 أشهر، سنة كاملة، أو عدد مخصص) — مع اقتراح تلقائي للمبالغ وتوزيعها تلقائيًا، وطباعة إيصال فوري (يوضّح تفصيل رسوم التسجيل ورسوم الشهر عند الدفع المشترك).
- **التقرير الشهري**: عرض حالة السداد (مسدد / جزئي / غير مسدد) لكل طالب في شهر معيّن، مع إمكانية التحصيل المباشر وتصدير CSV.
- **النسخ الاحتياطي**: تصدير/استيراد نسخة كاملة من البيانات بصيغة JSON، وتصدير قوائم الطلاب والدفعات والمصروفات ورواتب الموظفين بصيغة CSV.
- **المصروفات**: تسجيل مصروفات المدرسة (إيجار، كهرباء وماء، صيانة، قرطاسية...) بالتاريخ والفئة والمبلغ، مع تصفية حسب الشهر وعرض الإجمالي.
- **الموظفون والرواتب**: إدارة قائمة الموظفين (الاسم، الوظيفة، الراتب الشهري، الهاتف)، وتسجيل دفعات الرواتب شهريًا مع حالة السداد (مسدد/جزئي/غير مسدد) لكل موظف وطباعة إيصال لكل دفعة.
- **تحفيظ القرآن الكريم** (قسم مستقل تمامًا بقائمة تلاميذ خاصة به): إدارة الحلقات (كل حلقة لها أستاذ)، وتسجيل أعضاء كل حلقة بثلاثة أدوار — **طالب** (درس + مراجعة + حضور)، **مساعد** (حضور فقط)، **خاتم** (متابعة يومية بجلستَي صباح ومساء). كشف أسبوعي لكل طالب يسجّل الدرس الجديد (من سورة/آية إلى سورة/آية والمقدار) والمراجعة (من/إلى والمقدار) والحضور اليومي لخمسة أيام (السبت إلى الأربعاء)، وكشف يومي مستقل للخاتمين (بداية القراءة/المقدار/النتيجة لكل جلسة)، مع إمكانية طباعة كل كشف بنفس شكل الكشوف الورقية المعتادة.
- **إرسال عبر واتساب**: زر "📤 واتساب" بجانب كل إيصال دفعة وبجانب الفاتورة العائلية الموحّدة — يفتح محادثة واتساب مباشرة مع رقم ولي الأمر المسجَّل، ومعبَّأة تلقائيًا برسالة جاهزة (اسم المدرسة، تفاصيل المبلغ، رقم الإيصال) بنفس اللغة المختارة، فقط اضغط إرسال. رقم الهاتف يُنسَّق تلقائيًا برمز السنغال الدولي (221) إذا لم يكن مكتوبًا.
- **هوية المدرسة**: شعار قابل للرفع من صفحة الإعدادات (يظهر في القائمة الجانبية وأعلى كل إيصال/فاتورة مطبوعة)، اسم المدرسة بالعربي والفرنسي، ترويسة رسمية اختيارية (الجمهورية/الوزارة) ومعلومات الترخيص — تظهر تلقائيًا حسب اللغة المختارة. مُعدّة افتراضيًا لمعهد سرنج مختار اندمب جوب الإسلامي، ويمكن تعديلها أو استبدالها من الإعدادات لأي مدرسة أخرى.
- **الإعدادات**: السنة الدراسية، العملة (افتراضيًا **FCFA**)، رسوم التسجيل الافتراضية، بادئة رقم الإيصال.
- **ثنائي اللغة (عربي / فرنسي)**: زر تبديل اللغة في أسفل القائمة الجانبية يبدّل الواجهة بالكامل — بما في ذلك **الإيصالات والفواتير المطبوعة** — بين العربية (RTL) والفرنسية (LTR)، مفيد لأولياء الأمور الذين لا يقرؤون العربية. الاختيار يُحفظ تلقائيًا لكل جهاز.
- واجهة متجاوبة مع الجوال، تدعم الاتجاهين RTL/LTR بالكامل.
- **مزامنة مشتركة فورية (اختيارية)**: يمكن لشخص آخر (من هاتف أو جهاز مختلف) الاتصال بنفس بياناتك ورؤية أي إضافة أو دفعة **لحظيًا** — تسجيل طالب أو دفعة من أي طرف يظهر تلقائيًا عند الطرف الآخر بدون تحديث الصفحة. يعتمد على قاعدة بيانات Firebase مجانية تُنشئها أنت (Settings ← "الاتصال المشترك")، ثم يُنشأ **رمز مدرسة** قصير يُشارَك مع الطرف الآخر ليتصل به. بدون تفعيل هذه الميزة يعمل التطبيق تمامًا كما كان (محليًا فقط على هذا الجهاز) — لا شيء يتغيّر إن لم ترغب بها.

## التشغيل

لا حاجة لأي تثبيت. افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:

```bash
cd gestion-scolaire
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080` في المتصفح.

## ملاحظة هامة

جميع البيانات تُحفظ في `localStorage` الخاص بالمتصفح على هذا الجهاز فقط. يُنصح بأخذ نسخة احتياطية دوريًا من قسم **"النسخ الاحتياطي"** لتفادي فقدان البيانات عند مسح ذاكرة المتصفح.

## البنية

```
gestion-scolaire/
├── index.html      # ملف واحد قائم بذاته: الصفحة + التنسيقات + منطق التطبيق (Vanilla JS)
└── README.md
```

التطبيق مُجمَّع بالكامل في ملف `index.html` واحد (لا ملفات CSS/JS منفصلة) ليعمل بشكل موثوق عند فتحه مباشرة، أو عبر أي خدمة معاينة لا تدعم تحميل ملفات فرعية بشكل صحيح، أو بعد تفعيل GitHub Pages.
