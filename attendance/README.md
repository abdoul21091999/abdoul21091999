# برنامج حضور وانصراف الأساتذة

برنامج بسيط يعمل في المتصفح (ملف واحد `index.html`) بدون إنترنت وبدون خادم.

## التشغيل
افتح الملف `attendance/index.html` بأي متصفح (Chrome, Edge, Firefox) على حاسوب أو هاتف أو لوحة في مدخل المدرسة.
يمكن أيضاً نشره على GitHub Pages والدخول إليه عبر الرابط `.../attendance/`.

## الاستعمال
1. **الإعدادات**: اسم المدرسة، بداية ونهاية الدوام، مدة السماح للتأخير، أيام العمل، وكلمة سر الإدارة (اختيارية).
2. **الأساتذة**: أضف الأساتذة (الاسم، المادة، الهاتف). يمكن تعطيل أستاذ بدل حذفه للاحتفاظ بسجلاته.
3. **الحضور اليوم**: يضغط كل أستاذ على «تسجيل الحضور» عند الوصول و«تسجيل الانصراف» عند الخروج؛ يُسجَّل الوقت تلقائياً.
4. **السجل اليومي**: عرض أي يوم، تصحيح الأوقات، تسجيل إجازة أو عذر مع ملاحظة، تصدير إلى Excel أو طباعة.
5. **التقارير**: لكل أستاذ خلال فترة: أيام الحضور والغياب، مرات التأخير ومجموع دقائقه، الانصراف المبكر، مجموع الساعات ونسبة الحضور.

## ملاحظة مهمة
البيانات تُحفظ في متصفح الجهاز نفسه فقط. استعمل «تنزيل نسخة احتياطية» من الإعدادات بانتظام،
واستعمل «استرجاع نسخة» لنقل البيانات إلى جهاز آخر.
